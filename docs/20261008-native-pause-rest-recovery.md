# 现场暂停、休息与原任务恢复验收

基线：PR #7，`35edaa68a02fa68503b2d64fb893db670d171dd9`。仅原测试分支及独立测试 Worker。发布标识 `20261008-native-pause-rest-recovery`。

## 行为

- 经服务器授权后，单人／全员休息的任务卡仍可使用原派工人员或历史作业段建立查看上下文。打开卡片不创建任务、不插入作业段、不自动恢复计时。
- 原生作业和快递增加明确的“暂停整个任务／恢复整个任务”，复用中韩人员选择组件。整体暂停保留分配关系，关闭该任务当前有效计时；恢复须确认实际到位人员。只有借出人员、仍休息、已签退或另有任务时不能直接开工。
- 个人休息仅影响本人。结束休息核实原任务状态和当前分配；整任务暂停、已完成、已移除、签退或待借调归还不会被休息结束绕过。拣货子记录随实际段结束，合法恢复另建新段，旧工时保留。
- 非 owner 休息成员获得受限查看和结束本人休息入口，依据已验证现场会话、当前签到、未结束休息绑定和当前分配，不把历史人员快照当授权。不开放其他人的派审操作。原有 manager/owner/当前在岗成员权限保持，合法暂停操作人可恢复本人发起的仍有效暂停。
- 原生页面人员栏和人数共用实时详情更新；通用作业显示有效人分钟。完成后清理活动任务、导航上下文并回现场首页。
- 暂停不释放拣货／外部作业／装货单据占用。数据库拒绝重复派工、暂停装货时改数量或取消出库、暂停中提交成果或竞态完成。

## 数据和接口边界

新增 `sop_native_pause`、`sop_native_resume`、`sop_native_rest_return`，沿用 `sop_records`、`sop_events`、`v2_ops_jobs` 和现有计时段。暂停使用真实 `paused` 状态，不再以移除所有人员代替暂停。

增量安装测试环境约束触发器；不批量转换既有记录、不清空或复制业务数据。请求 ID、任务修订号、服务器身份和数据库事务约束用于重复提交／竞态保护。原正式开关不启用新接口。工时以人员真实工作段计算，不把暂停时间或单据关联数重复累计。
