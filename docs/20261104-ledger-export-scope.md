# FE-04 耗材流水导出范围提示

基线为当前已发布测试`89709cb5634af5a2e683b17b54c2ef9642bc3b38`，独立分支`feature/fix-ledger-export-scope-20261104`。不包含未放行的FE-03、FE-05或重置补丁；不读取/改写线上业务数据，不合测试/main、不部署。

## 问题与方案

流水接口统一最多返回200条，前端原先忽略`total`，导出直接使用这200条，按钮及文件名未说明范围。合成260条混合流水的实际API返回`total=260/items=200`。

本批采用已授权的明确截断方案，不新增全量分页导出。原因是当前全部记录接口分别对耗材和物品应用offset，再合并截取；不能直接循环offset保证完整集合。计数和明细也不是事务快照，不能将其包装为一致的全量导出。后续若开发全量导出，须独立处理这两个接口契约。

- 按钮改为中韩双语“导出当前列表CSV”；显示已加载条数和服务端本次计数。超过已加载数时醒目标明不是全量，建议缩小筛选再查，并在下载前二次确认；取消不创建文件。
- 文件名明确包含`current-N-rows`，避免离开页面后误认全量。保持原BOM、14列、字段内容、顺序和CSV转义，不追加破坏数据列的说明行。
- 导出绑定已成功查询的筛选及原读取身份。未查询的五个筛选字段改动、加载中、失败或登录/权限变化不能下载旧列表；原成功/失败竞态保护保留。
- 原生确认对话框返回后再次检查身份、读取token及筛选，旧页面或新查询不能下载之前的资料。
- 未返回、非法或相互不一致的计数不宣称完整，范围始终只是当前列表。导出不增加API请求、不遍历offset、不改服务端数量上限或权限。
