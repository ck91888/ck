# 签到、人力工时与测试系统界面更新

## 本次范围

仅独立测试站与开发分支。首页、现场执行、协同中心、耗材物品、数据看板、签到点使用统一的绿色界面、表单、弹窗、导航和移动布局。正式站的原页面、生产配置和主分支未修改。

签到点接入独立测试 D1，使用服务器韩国日期。临时日当生成当天工牌；长期日当使用已登记的固定工牌，每天签到。人力公司为 가온、포레인、동인천。补打与修改公司保留签到身份、时间与历史。固定工牌不印公司，避免换人力公司后旧工牌信息误导。

数据看板新增「日当人力」，展示全部签到人员、上下班、大货/代发/进口的个人作业时间、实际休息、未归属和其他/冲突。可按日期、公司、人员筛选、查看明细、核实补卡、管理长期工牌、处理同名人员、导出 CSV。不同部门重叠时间单列冲突，不重复归入部门；未归属不自动当作休息。已完成任务产出不按工时重复累计。

现场「人员与休息」使用人员卡片。开始休息关闭本人的计时段，结束休息仅恢复仍在进行且唯一的原任务。扫码下班只关闭本人参与，不结束同组任务。明确核实的补卡可关闭该班次未退出的个人作业段，不影响后续班次或整张任务。

「按单操作 → 大货操作」改为需求扫码、人员扫码、开工、同页填写产出与审核结束。任务创建与开工、填写产出与审核通过分别是同一数据库事务。作业单印独立二维码及共同来源；卸货选单展示同批要求。卸货已完成内容仍需现场交接确认，系统不会凭计划文字自动生成产出或扣减成果数量。

## 验证

- 40 项 Node + SQLite/D1 适配、真实 Worker 回归测试通过。包含原有业务、身份权限、幂等、事务回滚、多人参与、休息、签退、补卡、重复签到、公司修改、打印记录、部门冲突、日期边界和数据库内签到约束。
- 本地真实 Worker + 构建后原系统浏览器验证：签到成功、70×30mm 工牌生成、看板出勤与个人休息；手机按需求单连续加入两名日当，一人扫码签退后另一人继续，派审员填写产出一次审核完成。
- 1280×720 与 390×844 布局检查：首页、签到、现场、协同、耗材、人力看板；检查入库列表/表单、耗材表单、休息弹窗，修复原粘顶筛选遮挡及横向挤压。

## 实机验收事项

- 汉印 N51 已按 70×30mm 页面与二维码静区设置。实体打印机、驱动、扫码枪/PDA 摄像头和连续打印尚需现场试纸验证。浏览器打印请求不代表已确认出纸。
- 测试站延续现有免授权虚拟数据模式；这里不录入真实人员及财务资料。正式切换前需设置个人权限和签到点专用身份、完成备份和现场验收。
- 未签退的跨日班次、历史未退出作业以及未归属时间均须负责人核实，不能作为自动工资结算依据。
- 未以真实仓库规模开展压力测试、弱网实机测试或全量历史数据迁移。
