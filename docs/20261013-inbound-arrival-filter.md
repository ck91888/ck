# 入库计划预计到达日期筛选

本次基于 `ea27d785374d7e0b40d1c95b1acdd192e0f09163`，仅发布到 `upgrade/sop-safe-rollout-20260917` 和 `ck-v2-api-sop-staging`。系统现场反馈页面保持既有行为；作业计划列表的新需求后续独立实施。

## 使用和口径

在「协同中心 → 入库计划 → 查询筛选」选择「预计到达日期」起止日期。两端相同查询单日；只填一端表示该日起或该日止；范围包含两端。它可与建单日期、卸货完成日期、客户、状态、业务分类及记账状态共同使用。「清空预计日期」只清空这组日期，保留其他条件并重新查询。

筛选使用真正的 `v2_inbound_plans.expected_arrival`，不使用创建时间或实际卸货时间。业务日期遵循韩国日期：原日期直接比较，旧斜杠日期和无时区的本地时间保留业务日，有时区的旧时间转为 KST。未填写预计日期的计划在日期筛选时排除，清空后恢复。无效日期、结束早于起始均返回明确错误，不能悄悄扩大查询。

列表、分页总数和 CSV 共用同一服务端日期条件，在分页前筛选完整数据范围。既有取消、软删除和退件会话排除条件保留。不修改任何业务记录、历史日期或人员授权。
