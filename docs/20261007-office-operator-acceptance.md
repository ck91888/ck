# 协同中心操作姓名与计划审计

发布标识：`20261007-office-operator`。只部署 PR7 原测试分支，不合并、不修改正式 main 或正式系统。

## 使用与归因

办公室密码登录成功后，先填写并确认本次操作姓名。姓名须为1至40个可显示字符；空白、超长及控制字符不能继续。管理员账号、角色、部门、密码、Cookie、权限及有效期保持原样；姓名是自行填写的操作标签，不表示身份认证。

刷新和同一会话导航保留已确认姓名；退出后再次登录重新填写。协同中心右上角姓名可打开共用工作流样式的居中弹窗切换操作人。确认切换会重新加载，弹窗说明先保留未提交内容；取消保留原姓名和表单。

姓名存入独立的服务器会话操作上下文。业务请求携带非敏感的操作代次，服务器核对后才保存计划；请求中的 `created_by`、`by`、`operator_name` 等操作标签不作为归因依据。账户ID始终保留原真实登录账户ID。旧会话未确认姓名、旧页面代次不符、另一个标签切换人员或退出重登后，旧页计划写入拒绝。页面定时及焦点检查同步此状态，显示重新确认提示；可查看并保留未提交内容，再重新加载确认。

入库、出库创建及普通修改保存增量计划操作记录，在原详情页中显示创建人和操作姓名、创建/修改时间（KST）。出库原变更日志及 `last_modified_by` 同样采用服务器姓名；关联作业计划的 `sop_events.actor_name`、资料审计沿用该上下文。出库修改、原变更日志和新增操作记录同事务保存。历史创建人和历史事件不改写；功能启用前没有操作审计的历史不回填。

新增 `ck_office_operation_context`、`ck_plan_operation_audit` 及索引，按需初始化；未改认证表、部署凭据、生产入口、工牌身份、权限配置和认证生命周期。普通读取保持原权限。姓名代次保护针对协同计划及相关业务写入，未改考勤登记、账户管理和耗材模块原授权规则。
