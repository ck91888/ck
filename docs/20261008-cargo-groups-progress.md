# 按资料范围分组作业与出库

PR7 测试分支，基线 `15cb4f9ae20433e0e5a1ade1b06f7d522537f921`；发布标识 `20261008-cargo-group-workflow`。仅测试 Worker，未合并 main；没有迁移旧单或写入真实业务数据。此前暂停/恢复、单人休息后开卡与考勤相机修复均保留。

## 使用流程

1. 办公室002作业计划详情：一次上传多份资料；粘贴 Excel 制表符行（组名、箱唛范围、明确箱数、处理要求），逐组选择可复用资料及独立公共资料。一唛一箱须明确确认；可选总范围，不填写不会宣称没有遗漏。文件正文不改动。
2. 现场001扫描/输入箱唛查组，打开对应文件，打印分组对照表或标签。默认单步“作业”，不要求配置工序流；勾选本次实际货物组与人员派工。不同组可并行独立派工，只有明确填写同组 `贴标 > 打包` 等顺序时才约束前序审核。
3. 按实际箱/托完成、一次审核多组。输入箱数与实际成果单位分开，6箱可以打成2托。组完成不重复建工时；每次真实派工任务收尾登记一次工耗。各组审核独立放行，其余任务可以继续计时或暂停。
4. 办公室按组选择出库日期、去向和方式，自动继承该组成果数量、范围和确定的专用/公共文件版本。部分组内发货先按可定位实物范围拆组；已审核成果拆分后现场确认及重新审核，前序已完成审核留痕，原工时不重复。

直接转发计划沿用原出库流程。旧无组计划沿用现有整单操作，不解析备注、文件名或旧单为组映射。

## 一致性与权限

- 资料维护沿用办公室客服/管理员和部门权限；现场完成/审核按真实任务负责人、委托与角色权限；操作者取服务端会话。跨计划资料、组和任务拒绝。
- 版本和审计使用现有 sop_records/sop_events 原子事务。相同请求重试幂等，并发旧版本不能重复占用容量；需要派工后的变更原因与现场确认。
- 已提交/审核成果资料冻结；已预约及已发货数量持续占用，不因新版或拆组重置。只有未发货取消才释放。已分配组不能拆组，原文件引用保留。
- 拆分输出数量守恒、覆盖完整、无重复实物；前序真实任务先收尾，避免重复计量。拆分后的最终成果不自动获得出库许可。
- 分组计划旧整单完成、审核、取消、预约和数量调整入口禁止绕过。装货校验对应组全部必需操作审核通过，而不要求无关组先完成。
- 附件列表与计数按出库组快照返回；剩余资料上传和更改不污染已发批次。资料仅引用现有附件，无重复复制。
