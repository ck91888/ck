# 职员资料与每日打卡

新增职员签到，沿用既有中韩文签到点与70×30mm长期工牌打印。

- 数据看板 → 职员出勤 → 登记职员：姓名、工号、所属部门。在职状态可修改。工号可自动生成，登记后固定；同名职员用工号区分。
- 上下班签到 → 职员打卡：可扫描EMP职员工牌，或输入姓名/工号后核对人员。无需人力公司。重复签到/签退复用当天记录，工牌每日复用；补打不改变出勤时间。
- 职员资料支持更正姓名、调整部门、停用；当天历史姓名及部门保留原记录。未签退或未退出任务时不能直接停用，需先核实。
- 数据看板职员页单独显示日期、上下班、出勤时长及实际休息，支持CSV及负责人核实补卡。出勤时长表示上下班之间时间，未签退计至刷新时刻，不固定扣休息。沿用按韩国自然日的记录方式，漏签退从原日期核实补卡。
- 默认日当统计及公司汇总排除职员。现场人员与休息列表显示两类人员；职员也需要当天签到才可加入作业，签退仅关闭本人作业计时。

人员与每日考勤复用ck_attendance_people/days/events/breaks/prints；新增ck_employee_profiles保存独立职员工号、部门与资料版本，工牌前缀EMP。kind=permanent表示工牌长期有效，不代表长期日当身份。负责人权限和版本/请求幂等校验适用于职员资料变更。正式环境的attendance开关边界不变。

测试数据清空功能包含职员资料、职员工牌及每日打卡，确认弹窗已列明；系统登录账号、公司选项和库位仍保留。本次没有再次清空测试站数据。

70项自动化测试通过，其中5项新增场景覆盖权限、唯一工号、同名选择、职员和日当隔离、重复打卡、跨日期复用工牌、补打不改时间、资料修订保留历史、停用限制、签到/休息/签退作业限制。线上页面检查不添加虚构职员，等待用户登记自己的测试资料。
