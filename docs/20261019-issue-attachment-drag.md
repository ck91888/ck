# 新建问题点：拖拽选择附件

基线：`c6b9462ba7f980509cb6a4f8c17ac20dbe68ea93`。本候选只涉及协同中心问题附件前端及验收，不含混合单位出库改动。仅完成本地提交，尚未更新共享测试分支或部署；由父任务协调发布顺序。保留业务数据、现有权限和文件格式，不涉及数据库迁移。

## 行为

- `/002/ → 问题点沟通 → 新建问题点` 的附件虚线框可接收多张照片和文档混合拖入，并持续追加。拖入时高亮、显示松开提示，离开或取消拖拽后复位。
- 拖放和原有照片、拍照、文档按钮共用本地文件选择逻辑。选择期间不上传；提交时沿用原草稿上传、原子保存、失败保留、仅补传未成功文件及幂等重试流程。状态来自实际上传响应，没有新增百分比进度。
- 保持最多20个、每个20MB、文件名最多240字以及原扩展名范围。无效文件逐个列出文件名和拒绝原因，混合拖入的有效文件仍可加入。目录不遍历、不上传。重复判定沿用文件名、大小、修改时间，新增明确提示；达到20个时重复项仍显示为重复。
- 已选择文件可移除。提交中或结果待确认时禁止新增和移除；返回、新建及成功提交继续清理本地草稿和预览URL。没有新增删除已保存附件的路径。
- 仅在该新建页面拦截文件拖放默认行为，防止误拖到框外导致浏览器打开文件；普通文本拖选和其他页面不受影响。所有文件名仍以转义HTML或 `textContent` 呈现。
- 手机继续使用三个原按钮和拍照 `capture=environment`。中韩文均有拖放、重复与错误提示。
