# 日当派工权限（仅 SOP 测试环境）

本次基于 `9c324222ea2fbb92d0c384c5cac915c5154db90b`，目标分支为 `upgrade/sop-safe-rollout-20260917`，Worker 为 `ck-v2-api-sop-staging`。不改变 main、正式环境、真实人员授权或历史签到/作业归属。

## 使用

1. 办公室管理员进入「数据看板 → 日当人力 → 派工权限」。入口位于长期工牌管理旁。
2. 按本人长期工牌 DAF 核实档案，点击「开启」，明确选择用工部门、填写核实原因后保存。默认关闭，不设有效期；持续有效至管理员手动撤销。
3. 当天使用 DA 临时工牌时，在该长期档案下点击「关联临时牌」，扫描当天临时牌，核对双方工牌和本人身份，勾选确认并填写说明。姓名或公司相同不产生授权；既有签到和历史作业不合并、不改归属。
4. 本人当天有效签到后，使用已授权 DAF 或已明确关联的 DA 登录现场系统。每次新派工均重新校验授权部门、工牌状态、当天签到、签退及休息状态。
5. 「撤销」立即阻止新派工；已有任务仍可由原班组暂停、恢复和完成。权限变更及临时牌关联可在「记录」查看操作人、时间、原因和变更内容。

## 实现边界

- 功能仅在 staging、访问控制及考勤功能同时开启时生效。仅办公室 manager 可授予、调整、撤销或关联；现场角色不获得管理员能力，不能自授权或转授权。
- 授权以稳定 person_id 保存，DAF 大小写按原有规则保持；临时牌按现有规范化规则查找。临时关联明确到人和当日，拒绝重复签到、错人、跨日及覆盖已有映射。
- 新派工、任务派工、快递接收开始、接管、拣货加单及扩大班组均检查授权。授权版本和签到状态在业务写入事务内再次校验；撤销、休息、停用或签退并发时整批回滚，不留下任务、计时段或成功收据。
- 撤销后的原班组暂停/恢复/完成继续沿用原有任务归属校验。旧会话和旧版恢复接口不能借机加入新成员。
- 管理写操作沿用办公室实名操作上下文、版本冲突检测及请求幂等机制。授权、关联及审计在同一批事务提交。
