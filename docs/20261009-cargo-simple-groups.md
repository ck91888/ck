# 按组直接录入资料

基线 `15de6519b9185e80d8416fd5f7b6082283899731`。仅授权测试分支和 staging，发布标识 `20261009-cargo-simple-groups`。

每组默认仅范围、明确箱数、备注、本组多文件上传，选中文件即绑定该组，不再经过总池二次选择。组名自动生成；添加按钮保持列表末尾并滚动、聚焦新组。打托等无资料组沿用备注作为原因，不推断一唛一箱。公共资料、历史组名、区分标记、一唛一箱确认、复杂工序和批量录入保留在折叠设置中。新建入库、库存作业、入库追加和详情共用编辑器。

上传使用稳定文件/组标识，详情上传按计划串行更新版本，避免并发完成乱序；删组取消该组队列，迟到响应不恢复组或绑定到新组。失败可原请求重试，取消排队文件不再上传，重试不回退本地版本；保存防重复提交。资料快照、实际作业、分批出库仍使用既有校验和流程。
