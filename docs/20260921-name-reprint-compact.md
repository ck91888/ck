# 姓名补打与办公页面密度修正

工牌遗失后，补打入口默认按完整姓名查找，支持中文/韩文姓名及可选人力公司。候选显示公司、当天签到时间、上下班状态和工牌尾号；明确选择本人后进入原工牌预览并打印。同名不自动选第一人。查找临时工牌仅返回当天记录；长期工牌即使今天未签到也可找回。补打保留原工号与上下班时间，不新增签到。重复签到提示提供姓名找回入口。

协同中心采用下划线栏目、轻量筛选和连续列表，修复每页条数下拉框占据整行导致分页栏膨胀。单页仅显示一处统计与每页条数；多页保留翻页，手机简化为上一页/下一页。耗材及人力看板的统计改为横向摘要，收紧表格和容器间距。签到和现场扫码保留触摸尺寸。变更通过测试环境专用 CSS 注入，不改原模块页面源文件及生产配置。

验证（本地真实 Worker + SQLite 适配器，不向线上批量导入）：

- 42 项业务测试通过。新增同名选择、公司筛选、中文/韩文归一化、过期临时工牌/停用工牌排除、长期未签到、已签退后补打及权限检查。
- 浏览器按姓名检索两位同名人员，选中已签退者并请求补打；原两条签到记录及原工号/时间保留。韩文姓名找到未签到的长期工牌。
- 55 条虚拟入库计划：50 条一页、下一页 5 条，查询单条后仅一处分页。1440×900 筛选展开时首屏完整显示 6 条；分页高度 38px，普通记录约 65px；带备注记录自然增加高度。
- 390px 手机、1440px 桌面视觉检查，协同中心及补打页无水平溢出。复核人力表格、耗材摘要及浏览器脚本错误。
- 浏览器打印请求及 70×30mm 标签预览已验证；未连接汉印 N51，未验证实物出纸。
