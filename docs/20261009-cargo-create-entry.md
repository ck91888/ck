# 新建入口一次录入资料分组

修复基线：PR7 `2810d61541ef8356ae3d6c4dd04dc67f04db01ea`。发布标识 `20261009-cargo-create-entry`，仅测试分支和测试 Worker。

此前资料分组已进入保存后的作业详情，但遗漏了用户实际使用的“新建入库 → 添加作业计划”卡片；既有验收直接创建计划后进入详情，未覆盖该入口。本次补上新建入库内每张作业卡片、独立库存作业、既有入库内追加作业的分组与文件选择，复用现有编辑器，不要求用户先保存再跳回详情。

选择文件并加入可选资料后，按组或公共资料关联；点击页面提交时上传并一次保存。文件暂存使用独立草稿记录，不生成空作业单。最终事务一起保存入库、各张作业、分组快照、附件关联及创建重试结果。独立创建沿用原作业事务。文件按操作者与卡片草稿限定，内容摘要和请求标识防止覆盖；竞争创建、取消与认领使用现有版本审计守卫。

上传失败保留卡片和已上传进度；重新提交只补未上传文件。创建成功但响应丢失，重试返回同一批计划。上传中返回或关闭新建窗口会使后续响应失效并取消草稿；成功关联的文件不会被清理。没有资料组的旧整单创建仍可使用；直接转发继续原流程。资料组出库仍在对应实际成果审核后选择，不从输入箱数推定托数。
