# 大货派工与多人选择验收

现场执行从“按单操作 → 大货操作”进入负责人派工与审核。首页不再新增独立入口。协同中心的作业需求、已有任务链接也进入同一大货页面；原工单号扫码和开工作业表单继续保留。

## 验收步骤

1. 打开大货操作，查看派工任务与审核，切换查看作业需求，再返回任务列表。检查协同中心关联需求或任务链接也落在大货操作中。
2. 新建派工，分别输入 TEST-A|测试甲、TEST-B|测试乙，确认显示已选2人。工号与姓名首尾空格应被去除。
3. 选择乙为主操作员，再添加 TEST-C|测试丙、移除甲，主操作员仍为乙。
4. 重复输入 TEST-B|测试乙，显示已添加提示、人数不增加。输入同工号不同姓名时提醒核对工牌，不能覆盖原姓名。
5. 保存任务，刷新或通过原任务链接重新打开。打开调整人员，确认人员名单和主操作员保留。
6. 移除主操作员后，必须重新选择；即使再扫入其他工牌，也不能自动把主操作员改为第一人。
7. 在原工单号入口点击开始操作，按相同步骤选择多人，确认后原任务人数和人员一致。
8. 扫码枪回车应只添加工牌，不提交整个任务。相机连续识别同一工牌应短暂抑制重复回调，换下一张工牌可继续添加；关窗停止相机。

- Node自动回归：31项通过，包含人员选择、真实Worker的派工、工时、审核、原业务兼容及入出库关联。
- 本地真实浏览器：验证原菜单路径、连续添加三人、重复工号提示、空格处理、主操作员保持、保存和重新打开、重新指定主操作员，以及原业务三人开工。
- DOM脚本的旧首页选择器已改为原按单操作路径。本环境缺少jsdom，未执行该组DOM脚本；采用上面的真实浏览器验证。
- 实际手机相机和现场扫码枪硬件未在本次环境接入，需要现场验收；浏览器中已验证回车添加行为。
