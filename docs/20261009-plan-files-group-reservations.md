# 本作业资料与分组提前出库预约

发布标识：`20261009-plan-files-group-reservations`。仅 PR #7 测试分支 `upgrade/sop-safe-rollout-20260917`，以 `aa37ed6fda2771bc2aea581540ddd0a76d89efe6` 为本次基线；不合并 main，不操作正式或真实业务数据。

## 行为

- 新建入库中的每张作业卡、库存作业和已有入库追加作业，在计划数量/单位之后提供多文件资料入口。没有资料组也可一次提交保存，现场、作业详情和关联出库沿用该作业的资料，不创建占位组。
- 建组后，上述计划资料明确作为全部组共用资料；每组的直接上传只关联本组，不按文件名推断归属。
- 每组默认折叠“添加本组出库计划（可选）”。填入后，创建作业时即生成正常出库单，日期和运输方式按组独立保存。输入箱数仅表示待处理范围；审核前出库成果数量为零，不能开始实际装货。
- 同单位、同数量成果审核后自动填入原预约单；例如 6 箱加工成 2 托，办公室核对实际成果后一次确认，继续沿用原出库单号。
- 待确认预约可以在作业详情修改或取消。校验办公室权限、作业版本和出库更新时间；保留完整前后状态审计，同时写正常出库单版本及变更记录。运输修改沿用仓库变更确认标记。取消不删除原单和历史快照，释放后可明确重新预约。
- 正在作业、待收尾或已暂停的关联出库任务禁止修改/取消；并发开始装货、并发修改运输、取消或完成出库会使整个事务回滚。已实际出库快照不改写。
- 整单预约与分组预约冲突时阻止提交并保留输入。已有预约的组须明确取消预约后才能删除/拆组。新建成功结果包含分组预约单号。
