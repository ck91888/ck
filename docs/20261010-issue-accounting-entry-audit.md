## 修复

- 新问题界面缺失旧记账提醒流程。增加“提示客服记账”（备注选填）、“修改记账备注”和客服“确认已记账”，沿用原有待记账/已记账字段及列表筛选。展示首次提示人、时间、备注、确认人和时间；修改备注保留首次提示时间。反馈完成后客服才能确认，已记账不能重新提醒或清除确认。仅登记流程状态，不产生费用或修改账务明细。
- 新动作沿用部门/角色权限、版本冲突、原子审计和幂等请求。现场可提醒，不能确认已记账。新版问题的旧记账写接口与旧反馈写接口继续受保护；已作废问题只读。历史已记账问题迁移后保持原状态。
- 001 曾只隐藏旧“结束处理”按钮，遗留不能提交的反馈 textarea 和照片选择器。现在统一到上方“仓库反馈”弹窗，正文和拍照/相册位于同一有效表单。关闭、返回、跨问题切换保留各自内存草稿；上传中不允许提交反馈。迟到的照片上传只回到原问题、原处理轮次；完成反馈关闭作业并清除匹配的本地活动任务。
- 补齐当前处理轮次照片的现场上传/读取权限。上传限定当前有效轮次、部门、派审员或获授权的有效参与者、图片分类、类型和大小；署名来自会话。历史照片仍可按问题部门查看。列表使用包含处理轮次的附件集合，返回问题后恢复原轮次关联。
- 旧“暂时离开”被新版调整人员接管后，按钮改为实际动作名称。仅因导航丢失本地活动 ID 时，不再宣称人员已离开，而是提供“查看处理任务”。
- 001/002 问题详情、002 核对详情及计划关联面板增加当前记录/请求令牌检查，慢响应不会覆盖后来打开的记录。核对方式未识别或读取失败时不展示旧写按钮；失败可重试。计划旧附件控件在关联读取前隐藏，失败不重新暴露失效入口。
