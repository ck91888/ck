# 同车多计划卸货与派审员统一结束

范围：独立测试环境；生产主系统不变。

- 到仓卸货支持连续扫描计划号、计划二维码及已关联的外部入库单号。扫码逐单加入本车清单，同计划自动去重，可移除，搜索/勾选作为辅助。
- 每车最多20张计划，仅建立一个卸货工时任务。每张计划记录自己的实收明细；卸货中的状态修复、候选、详情及防删除检查可识别全部关联计划。
- 理货上架仍逐一完成所有外部入库单；直进直出、整托退回、换单按原规则自动入库；快递收货仍以逐件扫描为准。
- 旧临时卸货及计划卸货的派审员可统一结束多人任务。返回首页保留任务计时；重新进入临时卸货会恢复正确的反馈单关联。
- 全局工时和产出查询仍读取唯一原任务；计划详情仅展示本计划实收，不重复建立工时或产出记录。

验证：7项新增接口回归通过；39项原业务/入库规则/快递回归通过。浏览器本地实测连续扫三单号归并成两张计划、两人统一开工、逐单实收结束；三人临时卸货重新打开并由派审员完成。测试全部使用本地虚拟数据，用户现有任务未代填或代结束。

后续：继续审查其他原业务是否存在旧的个人退出/全员先离开限制，按当前派审员管理逻辑修正。
