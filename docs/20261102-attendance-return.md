## 已确认规则

- 保留稳定人员人日主记录、原ID及每日唯一约束，新增真实出勤子段，保留每次签退与审计。
- 误签退须主管按现有更正权限填写原因、核版本并保留前后值；本人重新扫码核对续作，不自动延长已关闭的操作/派审时段，不补缺口。
- 真正离岗后返岗须扫码确认，按服务器当下时间新增第2/3段；离岗间隔既非出勤也非休息。先记录真实出勤，再由主管确认加班属性。待确认或否认不删除事实、不等同工资结算。
- 返岗子段只扣实际登记休息，普通班次目标仅应用一次。按有效子段汇总操作、派审、休息、未归属和待核实，工时守恒。
- 每人同时一个开放段，多设备和重试幂等。签退关闭当前子段关联的操作、休息及派审；返岗不自动恢复旧作业或职责，需成功真实业务动作。
- EMP及日当长期/临时牌按稳定身份与明确关联处理；跨日韩国日期、原班次、过期临时牌和04:00保护一同适配。看板人日一行、人数去重，明细和CSV展示子段。
