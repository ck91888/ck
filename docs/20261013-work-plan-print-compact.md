基于已成功测试发布的 `3a4d9d9a87859115150cba9d11c742b904d30130`。只修改独立测试候选，不改变派工、完成、入库／出库或工牌打印逻辑。

入口为「协同中心 → 作业计划 → 查看作业单」。原单份和批量打印按钮自动记录，无额外“已打印”确认。

## 记录口径

- “打印未记录”表示没有可靠历史请求记录，不声称从未打印；“已发起打印”表示当前作业单内容已调用浏览器打印。“部分已发起”按批内有效作业单计数，取消单不计。
- 记录精确 need ID、要求版本、打印内容 SHA-256、当时 need revision、请求操作人和时间。作业要求／打印内容变化显示“需重新打印”。派工、暂停等仅改变业务进度且打印内容不变时，不要求重印。
- 浏览器无法证明实际出纸，也不能可靠识别打印窗口取消；取消仍属于已发起请求。弹窗被拦截、资料读取／页面准备／print 调用异常均不记录。
- 发生网络不确定时，同一个按钮重试同一个请求，只补登记、不再次打开打印窗口、不重复计数。再次正常打印是新的请求。
- 使用现有 sop_events，批量逐单原子保存；sop_revision_guard 阻止并发变化，不修改 need.state、revision、updated_at。专用指纹校验在泛型缓存回退前自行处理，冲突不会被旧成功吞掉。
- 原可打印角色能力保留，仍校验部门、取消／删除来源和操作身份；未增加派工权限。
