# 现场作业与计划表单调整（2026-09-22）

发布标识：`20260922-field-work-usability`。仅测试分支启用，原正式系统不受影响。

## 最终行为

1. 入库计划表单只让客服填写预计到达日期。建单日期由服务器按韩国日期自动记录，修改预计到达日期不会改变建单日期；旧计划历史日期保持原值。列表原日期筛选明确标为建单日期。
2. 按单操作新增明确的“外部作业单”入口，大货界面可切换需求作业单与外部作业单。外部单无需先建协同中心需求，继续使用原来的人员派工、工时、客户及产出记录。内部 NEED/SOPJOB 码和已有统一需求的出库单拒绝重复建外部任务。
3. 需求任务审核以已填产出为主，“附加操作”选填，不再要求重复写完成内容。货位支持直接拍照或相册上传，最多 8 张，每张 10MB；现场任务和办公室需求结果显示产出及可放大的照片。历史文字货位仍可查看。审核说明仍保留。
4. 打托结果上传旁提供 Excel 模板下载。首表字段与现有解析器完全一致，模板无样例业务数据，托盘号及箱唛按文本保存，避免前导零丢失；填箱唛但未填数量时仍按既有规则默认 1。
5. 出库详情关联作业链接直接指向对应需求详情，避免旧 `/sop/` 路径重定向到首页。

## 数据与权限

- 照片使用既有附件表与 R2；上传校验任务状态、派审权限、所属任务、数量、大小、MIME 和图片签名。上传人取登录会话，不信任表单自行填写的姓名。
- 结束任务只接受本任务的有效照片 ID，保存完整附件元数据到结果；重复提交保持原幂等行为。
- 模板由 `shared/templates/pallet-details.xlsx.b64` 随构建解码为 `/templates/pallet-details.xlsx`，不依赖在线第三方下载。
- 无数据库迁移，无历史数据批量重写。
