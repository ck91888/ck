# 入库计划打印下发状态

打印下发状态与“待到库、入库中、已入库”等物流状态分别记录。点击入库计划详情底部“打印”即记录当前版本已下发，不再需要单独确认。浏览器无法识别实物打印是否成功，取消打印也保留下发记录。

在协同中心 → 入库计划打开详情，点击详情底部“打印”。先打开窗口、读取最新计划并准备打印内容，再记录下发，保存成功后启动打印。窗口被阻止、内容准备失败不会下发；保存失败停止打印并提示重试。响应丢失时结果可能已保存，重试会核对同一版本且不重复记录。下发保存当前内部版本、操作人及首次时间，待到库物流状态不因此改变。

打印下发仍只允许原有办公室客服、管理员权限。重复点击在处理完成前锁定；同一版本重打不重复下发或覆盖首次人员时间。计划内容改变后需重新打印最新版本；读取与保存之间发生修改时拒绝旧版并停止打印。取消或删除的计划不得下发。返回或切换另一计划期间，迟到响应不切回旧详情。

列表及详情共享同一个下发徽章：未下发为深色琥珀文字/浅琥珀背景，已打印下发为深绿色/浅绿背景，需重新打印为深玫红/浅玫红背景，已取消为深灰/浅灰背景。徽章不再显示V2等版本后缀，后台及打印单的版本记录保留，中韩文长文案可在手机宽度换行。

本次按已确认要求从“预览后人工确认”切换为“点击打印即下发”。未改动内部API名称、数据库结构、身份验证或部署配置。实际物理打印与仓库交接仍由业务人员完成。
