# 入库计划打印下发状态

打印下发状态与“待到库、入库中、已入库”等物流状态分别记录。只打开预览、打印窗口或取消打印，不会自动标为下发。

在协同中心 → 入库计划打开详情，点击详情底部“打印”。核对当前版本，实际打印并交给仓库后，返回详情顶部点击“确认已打印下发”并确认。确认成功后显示“已打印下发”，保存当前版本、确认人及时间，待到库物流状态不因此改变。

确认按钮只对办公室客服、管理员开放，且需在当前页面打开当前版本预览才启用。刷新页面后要重新打开预览；返回列表再打开同一计划会保留当前页面的预览记录。计划内容改变后须重新打印最新版本，旧版确认不能覆盖新版本。已取消计划不得下发。

列表及详情共享同一个下发徽章：未下发为深色琥珀文字/浅琥珀背景，已打印下发为深绿色/浅绿背景，需重新打印为深玫红/浅玫红背景，已取消为深灰/浅灰背景。徽章保留明确文字及版本，中韩文长文案可在手机宽度换行。取消和重新下发不只靠颜色区分。

本次修复通用状态样式白字且无背景导致的不可读问题，并补充详情底部打印、顶部确认和刷新后预览要求的提示。未改变人工确认、版本校验、记录确认人时间和物流状态规则。
