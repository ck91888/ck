# 全界面整理与签到接入

范围：独立staging、原001/002/003/shuju及新签到页。用户已认可签到样稿并授权全部测试界面整理。不开生产开关，不合并main。

## 设计计划

沿用已认可的固定签到点风格：环境底#EEF3F1、纸面#FFFFFF、正文#223C36、主操作#18564A、分隔#D1DED8、待核实#976315。状态红绿只表达结果，不把正常完成设成危险操作。中文Microsoft YaHei、韩文Malgun Gothic，主文16px，手机主按钮至少48px。

全系统共用明确模块导航、页标题、查询筛选、列表、详情和表单样式。001手机/PDA单列，以扫描和本单动作为主；002与003桌面展开表格和分区资料；shuju表格数字对齐、个人明细可追溯；签到电脑保持简洁，不展示全员财务记录。

```text
系统导航：现场执行 | 协同中心 | 耗材物品 | 数据看板 | 上下班签到
模块标题                     当前身份 / 语言
本模块业务标签
筛选 / 扫码 / 主要动作
列表或单据详情
```

审视并删掉无关装饰：不用营销大标题、背景渐变或满屏重复卡片；有真实分组才用面板。手机长工作流程放在页面内，短修改才用居中弹窗。既有模块入口保留，修正扫码和任务之间重复制单的路径。

## 数据原则

日当名单来自当天考勤，工时来自原个人参与时段。长期固定牌每日签到、临时牌带日期；公司更正保持工号和签到时间。实际休息明确记起止，不按固定午休扣。下班停止本人时段，留待核实，不结束多人任务。工时不按人数均分。未归属、跨部门重叠和跨日遗留明确列出。
