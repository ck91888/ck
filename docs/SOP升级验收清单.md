# 上线前验收清单（待实际环境验证）

| 场景 | 必须观察到的结果 |
|---|---|
| 旧任务升级前已开工 | 升级后原人员正常退出/完成；原开始时间、成果、日志保留 |
| 负责人只派工、不干活 | 不增加负责人操作工时 |
| 提前派单 | 未点开始不计工时 |
| 两位负责人同时派同一人开工 | 只能一项成功，失败任务及日志不出现半写入 |
| 网络掉线后重试同一次开始/完成 | 只有一次任务变化、一次计时段/成果 |
| 增员、减员、暂停、恢复、整改 | 每段实际工时可追溯，审核等待不计入 |
| 客服在仓库操作中修改要求 | 页面明显提示；旧版本确认不能覆盖新修改；最新要求确认后才能反馈 |
| 新建含操作的出库计划 | 仅生成一项作业需求，出库详情引用它；不再重复执行旧库内操作 |
| 新任务审核不通过 | 原任务返工，出库不能跳过审核 |
| 清点100箱，60箱出库、40箱留仓 | 操作成果只记100；同一出库单不能重复关联；剩余去向可查 |
| 11点核对完，13点追加 | 原有效核对结果保留；新增未核对；11点结束不关闭总批次 |
| 修改已核对条码数量 | 仅该条码重新核对，原操作历史保留 |
| 删除已核对条码 | 记录原因与货物去向；不能悄悄减少计划掩盖异常 |
| 改出库日期 | 原日撤销记录保留，新日待复核；目标冲突不能半移成功 |
| 关闭清单 | 无缺口、无未复核异常且明确交接后允许 |
| 手机扫码、中文韩文、弱网、Excel前导零 | 实机通过，不以桌面语法检查代替 |
| 耗材采购、收货、领用、退回 | 原003完整回归通过 |
| 数据库备份 | 在另一环境可恢复，并验证关键表数量 |
| 停止接收新版新任务 | 已开始任务仍可完成，不丢失生产期间增量 |
