# 多个外部入库单关联同一计划

理货上架的外部系统入库单号支持每行一个，或使用中英文逗号、分号分隔，最多50个。相同单号归一化去重；其他有效计划已使用的单号拒绝重复关联。

现场代发入库／大货入库扫描其中一个外部号，匹配原入库计划并明确显示“本次外部入库单”。候选列表逐单列出未完成项；完成的单号不能重复开工。每单有独立任务、人员区间与实际产出，不复用另一单的任务。多单任务的本次入库数量不预填整批数。

例如计划A关联A1、A2：A1完成时，办公室和现场显示1/2，计划保持部分入库完成；A2完成后显示2/2，理货上架类型才完成。若计划还有其他未完成环节，仍须完成那些环节。重复结束不再累计产出。多单未全部完成时，手动整单完结入口也不能绕过。

未开工计划可修改单号。理货中禁止更换；已完成单号不可删除或换号。等待中的其他单号可更正。旧单号输入及已存在的单号、任务继续兼容。

技术：原external_inbound_no字段使用规范化换行分隔，API同时接受external_inbound_nos数组。v2_ops_jobs新增inbound_external_no，按实际任务计算逐单进度；有独立唯一索引和引用有效性检查。schema版本v2.20260922a。没有新增测试清空表，既有备份范围自然包含新增列。

日期体验：测试系统统一点击日期框任意位置打开原生日历；原生图标的点击范围覆盖完整输入框，保留键盘编辑。覆盖动态表单与日期时间选择。
