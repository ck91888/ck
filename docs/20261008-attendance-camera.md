# 日当签退与职员上下班相机扫码

仅 PR7 测试环境。基线 `7f28287dd817f7c3b67499876547b608314c0d94`，发布标识 `20261008-attendance-camera-confirm`。资料范围分组仍在另一隔离目录，本次不包含。

日当下班签退、职员上班和下班表单新增手机相机扫码按钮，复用构建已包含的本地 Html5Qrcode 库，默认后置相机。点击按钮才请求相机。扫码只填工牌编号，不提交考勤；用户核对后继续点击原确认按钮。原手输、扫码枪、职员同名选择和全部后端校验沿用。

扫码只取 `badgeId|name` 中的工牌编号；日当只接受 DA/DAF，职员只接受 EMP，姓名仍来自登记记录。识别成功、关闭、切换上下班/人员类型、表单替换、页面隐藏和退出均释放相机；启动晚到及过期回调不填写新表单。重复帧、重复打开、Enter 与确认并发不会重复提交。考勤请求进行时锁定输入，旧响应不能覆盖新页面。权限拒绝、无相机、相机占用或浏览器不支持均提供中韩手输回退。

验证：`tests/attendance-camera.test.mjs` 覆盖12项模拟媒体/生命周期/防重/回退用例；`tests/attendance-camera-browser.mjs` 在真实构建签到页、真实 Worker 与内存 SQLite 上验证日当签退及职员上下班。浏览器使用生成的视频流和模拟识别码，检查真实 MediaStream 轨道停止；识别后数据库不变，显式确认后每人只保留一条考勤。另验证未登记职员拒绝、手机390px与桌面布局，并检查截图。没有操作真实签到，没有物理手机相机实测。

测试输出保存在执行器 `/tmp/ck-camera-*`，实际发布提交与 Cloudflare 构建须按最终报告核对。
